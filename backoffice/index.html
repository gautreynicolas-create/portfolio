Connexion à ton site

Le back-office enregistre directement sur ton dépôt GitHub. Ces informations restent uniquement sur cet ordinateur, dans ce navigateur.

Utilise un token classique (pas "fine-grained" — ces derniers ne supportent pas encore l'enregistrement). Sur GitHub : Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token. Coche uniquement la case "repo". Créer un token classique →
